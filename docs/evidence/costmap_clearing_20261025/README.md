# 局部障碍残留与膨胀范围修复

操作者报告：人离开后原位置仍有障碍拖影，软代价区域过宽。旧截图来自之前的相机导航会话，不能等同于本轮现场截图。

现场局部地图约 7.89 Hz、障碍点云约 5.51 Hz、导航原始点云约 5.92 Hz，地图发布并未停止。旧 VoxelLayer 的垂直体素可能被后来的地面射线从下方绕过，旧的人体高度体素继续占据投影。

Bunker 配置改用原生 ObstacleLayer：障碍点云标记，导航原始点云进行二维射线清理。上游地面/高度/自体过滤保留；原始 LIO 输入不变。层级与观测源高度范围同步为 odom 中 [-3.0,3.4] m，避免默认 min_z=0 丢失低障碍。局部/全局膨胀 0.85/1.0 → 0.65/0.80 m，衰减 2 → 3；RPP 参数对应同步。车体尺寸、padding、碰撞检查、速度和新鲜度检查不变。

隔离 DDS 域内运行真实 Nav2 插件：旧 VoxelLayer 在人离开并出现地面射线后仍为 lethal=100，新层变为 free=0；人持续存在或再次出现时仍为 100，0.15 m 高低障碍仍为 100。断流不会按 TTL 删除障碍，恢复清理证据后才移除旧人体位置。附带验证缩小后的膨胀范围。

构建 `colcon build --packages-select agt_field_test_bringup --symlink-install` 通过。相关回归 **106 passed in 60.98 s**，涵盖真实 Nav2 清理、距离路径、组合/分开启动、任务、时钟及拍照配置。新增膨胀断言初次取样覆盖边缘栅格而失败，修正取样点后重跑全套通过。

证据保存在工作区 `runs/costmap_clearing_20261025/`：`before/` 保留源码/配置/测量表备份，`isolated/result.json`、`live/`、`build.log`、`regression_final.log`。未清理工作区或修改依赖 HEAD。补丁由 Workbench `profiles.py` 生成，可随版本保留并在初始化后重新构建；不需要修改锁定原生依赖。

实车修复后的离人清理和更窄膨胀范围仍需现场验证。本次不增加物理通过标签，不将合成测试当作实车验收。
