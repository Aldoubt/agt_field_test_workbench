## 现场现象与原因

操作人员确认：车后方杆件发生晃动，杆件自身的激光回波进入局部障碍地图，形成障碍及膨胀区域，触发导航停车。

本次会话附带 RViz 截图显示 Global Costmap、Local Costmap 均启用，Navigation 为 active，Feedback 为 aborted，Recoveries 为 0，仍可见绿色规划路径。截图只能佐证界面状态；杆件晃动与自身回波的关联来自操作人员现场确认，尚未用本次对应点云逐帧量化。

该问题不应直接归因于局部地图停止更新：自回波持续进入观测源时，即使地图正常更新也会反复标记障碍。杆件是否超出原有静态自过滤盒、是否有历史障碍清除延迟，仍需点云与代价地图对照确认。

## 待整改与复测

1. 优先固定后方杆件及连接件，减少行驶、转向和停车时的摆动。
2. 在 base_link 坐标系测量杆件静止与最大摆动范围，再评估现有自过滤盒覆盖情况，避免无测量依据地扩大屏蔽区域。
3. 用 `./field_trial record` 同步录制过滤前后点云、TF、局部代价地图、导航反馈和速度链路，对比固定杆件前后的表现；确认真实外部障碍仍可正常标记和避让。
4. 复测通过标准：杆件自身回波不再进入导航障碍层、不再因该回波停车，同时局部障碍标记与清除正常。

## 2026-10-27 后部盒增高试验

按操作人员请求，工作区 `config/robots/bunker.yaml` 与仓库模板同步将第二个盒的 zmax 从 1.00 m 提高至 1.68 m。当前 base_link 范围：x=[-0.95,-0.60]、y=[-0.12,0.31]、z=[0.82,1.68] m。第一盒及后部盒 XY / 下沿保持原值。1.68 m 取现有上部支架盒高度作为试验值，并非杆件完整摆动包络的测量结论。

该固定盒随 base_link 移动，覆盖盒内杆件的动态摆动回波，但不会追踪杆件；超出 XY 或高度范围的回波仍会保留。盒内真实外部障碍也会被过滤，因此应优先固定杆件并根据实测收紧范围。修改只进入导航预处理器 self_filter.extra_boxes，不改变 LIO 或重定位输入，不应作为全局匹配失败的修复。

配置在新会话生成导航参数时生效，无需编译。停车结束旧会话后，用原启动命令重新启动；不要直接修改旧运行参数文件。静止时对照 /agt/livox/points、/agt/navigation/points_obstacles 和局部 costmap，检查摆动回波是否消失、盒外真实障碍是否保留；若杆件横向越界，需测量后单独调整 XY，不能仅继续增高。复测前不标为已修复。回退只需将第二盒 zmax 恢复为 1.00 m。
